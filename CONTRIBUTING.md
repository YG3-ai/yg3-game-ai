# Contributing

Open an issue to propose a lesson or report a reproducibility problem. Pull requests should keep each chapter runnable on its own and describe the observations, actions, reward or labels, and evaluation split. Include the commands and results you actually ran.

Use original or permissively licensed tutorial assets only. Do not submit other characters from the private game, credentials, raw captures, or weights whose source and distribution rights have not been reviewed. A screenshot or clip used as an example should identify its owner and license separately from the tutorial code. Preserve the asset credits in ASSETS.md.

# 贡献指南

欢迎通过 Issue 提议新章节或报告可复现的问题。Pull Request 应保证每章都能独立运行，并说明观察数据、动作、奖励或标签，以及评估所用的数据划分。请写明实际运行过的命令和得到的结果。

教程资源应为原创，或采用允许相应使用方式的许可证。请勿提交私人游戏中的其他角色、凭据、原始采集数据，或来源及分发权尚未确认的权重。作为示例使用的截图或视频，应单独注明其所有者和许可条款。请保留 [ASSETS.md](ASSETS.md#mandarin) 中的资源署名。
